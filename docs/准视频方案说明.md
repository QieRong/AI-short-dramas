# 准视频方案 —— 技术验证说明

> 目的：在 Agnes 视频 API 免费层限流严重的情况下，验证"静态图 + FFmpeg 运镜"
> 作为备选（或混合方案组成部分）的可行性。
>
> 生成时间：2026-10-10 ｜ 状态：**待用户评估**

---

## 一、原理

用 FFmpeg 的 `zoompan` 滤镜，为静态图（分镜图 / 角色护照图）添加**连续的推拉摇移**，
输出标准 MP4。本质是"动态化的静帧"，而非真实运动生成。

**关键参数（已固化在 `scripts/kenburns.py`）：**
- 输出：720x1280（9:16 竖屏）、30 fps、H.264、yuv420p
- 时长：默认 5 秒
- 预处理：先放大 2×（1440x2560）再 zoompan，消除缩放抖动/锯齿

## 二、四种运镜

| 代号 | 效果 | 适用场景 |
|---|---|---|
| `in` | 缓慢推近（1.0→1.25 倍） | 强调、逼近情绪、特写 |
| `out` | 缓慢拉远（1.25→1.0 倍） | 揭示环境、交代关系 |
| `left` | 向左平移（1.15 倍下横移） | 扫视、跟随视线 |
| `right` | 向右平移（1.15 倍下横移） | 同上，方向相反 |

## 三、本次验证产出

测试素材：`04_assets/characters/角色护照.png`（锁定护照）

| 文件 | 运镜 | 时长 | 分辨率 | 体积 |
|---|---|---|---|---|
| `角色A_in.mp4` | 推近 | 5s | 720x1280 | 324 KB |
| `角色A_out.mp4` | 拉远 | 5s | 720x1280 | 328 KB |

| `角色A_right.mp4` | 右移 | 5s | 720x1280 | 240 KB |

均通过 ffmpeg 校验：H.264 / 720x1280 / 30fps / 5.00s / yuv420p。

## 四、与"真视频"的差异（客观评估）

| 维度 | 真视频（Agnes API） | 准视频（FFmpeg 运镜） |
|---|---|---|
| **画面运动** | 人物/物体的真实动态（眨眼、转身、风吹） | 仅镜头缩放平移，画面内容静止 |
| **成本** | 免费层限流严重（当前几乎不可用） | **零成本、无限次、本地秒级** |
| **一致性** | 需图生视频参考，仍有漂移风险 | **完美一致**（同一张图） |
| **可控性** | 依赖模型理解提示词 | 精确可控（运镜参数确定） |
| **信息量** | 可表达剧情动作 | 只能表达"强调/揭示"，无法表达新动作 |
| **生成速度** | 数分钟/片段 | 数秒/片段 |

## 五、结论（待用户判断）

准视频方案的**强项**：零成本、完美一致性、绝对可控 → 适合**静态对白、氛围镜头、
转场、情绪强调**类镜头。

准视频方案的**短板**：无法表达人物动作 → 关键动作镜头（开枪、转身、撞柜）
仍需真视频。

→ 这正好支撑**混合方案**：关键动作镜头用视频 API（每集 3-5 个），
其余用准视频。
