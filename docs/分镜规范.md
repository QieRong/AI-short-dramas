> 本文件是剧本与分镜的**质量判定标准**。任何 Agent 生成或修改剧本/分镜前必须先读本文件。

## 一、镜头级规则（最核心）

### 1.1 铁律：一个 5 秒片段 = 一个主体动作

| 规则                    | 说明                                         |
| ----------------------- | -------------------------------------------- |
| 单镜头时长 ≤ 5 秒       | 由 `agnes-video-2.5-flash` 单次生成上限决定  |
| 单镜头只含 1 个主体动作 | "后退+扣扳机"是 2 个动作，必须拆             |
| 复杂动作拆成多个镜头    | 拆镜头 ≠ 加时长，是切成多个 5 秒片段         |
| 单镜头只含 1 个视觉焦点 | 特写就特写，全景就全景，不要"从特写拉到全景" |

### 1.2 什么是"一个主体动作"

✅ **合格**：
- 角色A后退一步
- 角色B扣紧扳机
- 角色C转身
- 手指按下扳机

❌ **不合格**：
- 角色B后退并扣紧扳机（两个动作）
- 角色A撞翻铁柜，灰尘弥漫（撞+灰尘是因果，不是同一动作，但需拆为"撞"和"灰尘"两镜）
- 枪口挑起下巴，角色B冷笑（动作+表情，可同镜但需慎用）

### 1.3 动作拆分示例

| 原始描述                   | 拆分结果                                      |
| -------------------------- | --------------------------------------------- |
| "角色B后退，扣紧扳机"      | 镜头A：角色B后退一步 / 镜头B：特写手指扣扳机  |
| "角色A瞳孔剧震，后退，撞翻铁柜" | 镜头A：瞳孔特写 / 镜头B：后退一步 / 镜头C：撞翻铁柜 |
| "食指按下扳机，画面黑屏"   | 镜头A：食指按下 / 镜头B：黑屏（1秒空镜）      |

## 二、场景级规则

### 2.1 单集场景数量上限

| 集时长   | 场景上限 | 理由                                     |
| -------- | -------- | ---------------------------------------- |
| 45–60 秒 | 2 个场景 | 每个场景都需重建一致性，场景越多风险越高 |
| 60–90 秒 | 3 个场景 | 上限，不建议超过                         |

### 2.2 同场景合并原则

若相邻两场戏**物理位置相同**（都是走廊、都在车内），**必须合并为一个场景**，用镜头切换区分段落，不要拆成两个场景。

**反例**：某集原稿把"走廊羞辱"和"走廊对峙"拆成两个场景 → 已修正为合并。

### 2.3 场景切换必须有过渡

跨场景时必须有一个**过渡镜头**（3–5 秒），说明角色如何从 A 到 B，否则观众困惑。

## 三、剧集级规则

### 3.1 单集时长

- **不强制等长**。短剧核心是节奏，不是对称。
- 单集建议范围：**45–90 秒**。低于 45 秒内容单薄，高于 90 秒信息过载。
- 允许相邻集数时长差异，但**第 1 集建议 ≤ 60 秒**（抓住观众注意力）。

### 3.2 伏笔密度

| 规则                    | 说明                                       |
| ----------------------- | ------------------------------------------ |
| **每集最多埋 1 个伏笔** | 两个伏笔连续出现会相互削弱，观众抓不住重点 |
| 伏笔呈现方式优先级      | 视觉伏笔（一闪而过）> 台词伏笔 > 字幕伏笔  |
| 伏笔不得自我解释        | "镜像…该醒了"可以，"镜像计划是…"不行       |

### 3.3 结尾钩子

- 每集结尾必须**定格在一个未完成的动作或未解的符号**上
- 禁止结尾角色说"我终于明白了"
- 允许结尾黑屏 + 画外音 / 字幕 / 音效

## 四、台词级规则

### 4.1 字数与句式

| 规则                   | 说明                     |
| ---------------------- | ------------------------ |
| 单句 ≤ 15 字           | 适配 Edge-TTS 与视频模型 |
| 单集总台词 ≤ 300 字    | 超过则信息密度过载       |
| 全动作化，删解释性对白 | "他背叛了我"→ 一个耳光   |
| 每句必须有潜台词       | 台词只说表面，真意靠表演 |

### 4.2 禁止的台词类型

| 禁止类型         | 反例                        | 修正                         |
| ---------------- | --------------------------- | ---------------------------- |
| 反派自我介绍     | "我叫某某，记住这个名字"    | "二十年前你没记住，现在呢？" |
| 角色说出内心想法 | "我很害怕"                  | 手抖、后退、屏息             |
| 解释性对白       | "因为她是某家长女，所以她…" | 直接切下一个镜头             |
| 书面语           | "此次行动的目的在于…"       | "我要找她。"                 |

## 五、交付前自检清单

Agent 在向用户交付剧本/分镜前，必须逐项自检：

- [ ] 每个镜头 ≤ 5 秒？
- [ ] 每个镜头只含 1 个主体动作？
- [ ] 单集场景数 ≤ 2（45–60秒）或 ≤ 3（60–90秒）？
- [ ] 同物理位置场景已合并？
- [ ] 跨场景有过渡镜头？
- [ ] 单集伏笔 ≤ 1 个？
- [ ] 单句台词 ≤ 15 字？
- [ ] 单集总台词 ≤ 300 字？
- [ ] 无反派自我介绍？
- [ ] 无角色说出内心想法？
- [ ] 结尾定格在未完成动作/未解符号？

**任一项不通过 → 自行修正后再交付，不得带着已知问题交付。**
