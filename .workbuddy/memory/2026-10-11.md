- 官方错误码页 `wiki.agnes-ai.com/zh-Hans/docs/code`：**401** = 认证失败，成因为
  「Key 不正确 / 已过期 / 配置不正确 / Header 缺 Authorization / **Key 属于其他账户**」；
  402 = 余额或配额不足（查 Token Plan 与 Key 类型）。
- FAQ 页：401 = Key **无效、已删除、格式错误或 Bearer 后缺空格**。

- 推论：`This token status is unavailable` 属**令牌状态级**文案（非通用「无效 Key」），
  说明服务端认得该 Key 但状态不可用 → 对应「Key 失效/删除」或「Key 与账户（站点）不符」。
- 处置建议：控制台**重新生成 Key**（同时覆盖两种可能）→ 替换 `scripts/.env`。
